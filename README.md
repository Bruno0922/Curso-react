# 🚀 Curso de React Para Iniciantes

Repositório com minhas anotações e resumos do curso **[Curso de React Para Iniciantes](https://www.youtube.com/watch?v=hd2B7XQAFls&t=1588s)**, ministrado por **Dimitri Teixeira** no YouTube.  

O curso é voltado para iniciantes e apresenta os fundamentos do **React**, incluindo **componentes, JSX, props, estado e rotas**, de forma clara e objetiva.

---

## 🎯 Objetivo do curso
Aprender os conceitos básicos do React e construir uma base sólida para desenvolver aplicações web modernas, escaláveis e organizadas.

---

## 📑 Conteúdo do curso

- **Introdução ao React**
  - O que é React e por que usar
  - Preparando o ambiente

- **JSX**
  - Estrutura básica
  - Diferenças entre HTML e JSX
  - Boas práticas

- **Componentes**
  - Componentes funcionais
  - Estrutura e reuso de código
  - Comunicação entre componentes

- **Props**
  - Passagem de dados entre componentes
  - Props dinâmicos

- **Estado (State)**
  - Introdução ao `useState`
  - Atualização e manipulação de estado
  - Diferença entre props e state

- **Rotas**
  - Introdução ao React Router
  - Configuração de rotas
  - Navegação entre páginas

- **Projeto prático**
  - Aplicação simples usando todos os conceitos estudados

---

## 🔑 Conceitos principais aprendidos

- JSX como forma de escrever elementos React
- Diferença entre **componentes** e **elementos**
- Comunicação de dados via **props**
- Gerenciamento de dados internos com **state**
- Criação de rotas usando **React Router**

---

## 🛠️ Exemplos práticos

- [ ] Criar componente de botão reutilizável  
- [ ] Criar contador com `useState`  
- [ ] Criar sistema de navegação com múltiplas páginas
